# SecureCalcPro

**SecureCalcPro** is a Java calculator application with **user login, registration, and personalized calculation history**.  
It features a dark-themed GUI with support for arithmetic operations and automatic history saving per user.

---

## Features

- User login and registration system
- Personalized calculation history per user
- Supports arithmetic operations: `+`, `-`, `×`, `÷`, `%`, and parentheses
- Clear (`AC`) and evaluate (`=`) buttons
- Dark-themed user interface (login & calculator)
- Automatic saving/loading of user history

---

## Important Note

> This application uses **Java Swing for GUI**.  
> It **cannot run in environments without a graphical display**, such as headless servers, CLI-only Linux, or GitHub Codespaces.  
> Attempting to run it without a GUI will produce a `HeadlessException`.  

This repository **contains only the source code**. To run it, you need a **local desktop environment** (Windows, macOS, or Linux with GUI).
